# ТОП Афиша | TopAfisha

Русскоязычный статический сайт (SSG) мероприятий в Израиле. Партнёрский сайт Bravo (`top.kassa.co.il`).

- **Домен:** https://topafisha.co.il
- **База покупки (партнёр):** https://top.kassa.co.il
- **Сайт-близнец на иврите:** https://idir.co.il

## Структура

| Файл | Описание |
|------|----------|
| `shows.json` | Источник данных (русский фид, ~650 мероприятий, `{ Shows: [...] }`) |
| `build.js` | Скрипт сборки (Node, без зависимостей) → `dist/` |
| `fetch-shows.js` | Загрузка фида Bravo → `shows.json` (`npm run sync`) |
| `serve.js` | Локальный dev-сервер (порт 4321) |
| `dist/` | Результат сборки (не хранится в Git) |

## Сборка

```bash
node build.js
```

## Локальный просмотр

```bash
node serve.js
```

Затем откройте http://localhost:4321

## Возможности

Живой поиск, фильтры (категории / города / даты), постраничная загрузка, виджет доступности,
иерархические URL, полный SEO (Schema.org Event, sitemap, canonical, Open Graph), реклама AdSense.
Язык: `ru`, направление: `ltr`.
